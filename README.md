# Playwright Async Parser

Высокопроизводительный асинхронный инструмент для параллельного сбора данных с веб-ресурсов, использующих динамический рендеринг JavaScript. Проектирование архитектуры ориентировано на эффективную утилизацию сетевого канала и минимизацию накладных расходов памяти (OЗУ) при работе с пулом конкурентных задач.

## Архитектурные особенности и паттерны
*   **Изоляция конкурентных контекстов (`asyncio.gather`):** Конвейер выполняет одновременную инициализацию пула корутин без последовательного блокирования потока. Сбор данных со страниц происходит параллельно.
*   **Управление системными ресурсами (`page.close()`):** Принудительное закрытие контекста вкладок после извлечения DOM-дерева. Исключает риски утечек памяти (Memory Leaks) под высокой Highload-нагрузкой.
*   **Оптимизация runtime-операций (List Comprehensions):** Преобразование и развертывание многомерных массивов (матриц результатов `asyncio.gather`) реализовано через списковые включения. Исключены медленные вызовы метода `.append()` на уровне ядра интерпретатора.
*   **Контекстный менеджмент файловой системы (`with open`):** Безопасная запись сериализованного JSON-массива на жесткий диск с контролем закрытия дескрипторов и форматированием отступов.

## Технологический стек
*   Язык разработки: Python 3.8+
*   Асинхронное ядро: Playwright Async API (Chromium)
*   Обработка DOM: BeautifulSoup4 (html.parser)
*   Сетевая маскировка: Fake-Useragent
*   Формат хранения: JSON / Контекстные менеджеры
